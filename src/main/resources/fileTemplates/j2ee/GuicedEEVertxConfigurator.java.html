This is a built-in template for a GuicedEE Vertx Configurator.
A Vertx Configurator composes options(VertxOptions) on the shared options before builder(VertxBuilder). Preserve metrics, event-bus endpoints and pool sizes; do not replace them with a new options object or create another cluster manager.
This class will be automatically registered as a service loader implementation.
Predefined variables:
${NAME}   Name of the class to create
${PACKAGE_NAME}   Package name
